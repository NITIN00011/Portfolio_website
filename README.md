# 🚀 Personal Portfolio Website

A modern and responsive full-stack portfolio website built using React.js, Node.js, Express.js, and MongoDB.

## 🌐 Live Demo

Frontend:
https://portfolio-website-plum-two-p1t8bimbi3.vercel.app/

GitHub Repository:
https://github.com/NITIN00011/Portfolio_website

---

## ✨ Features

- Modern Dark UI
- Fully Responsive Design
- Animated Hero Section
- Framer Motion Animations
- Typewriter Effect
- Resume Download Feature
- GitHub & Social Links
- Contact Form Integration
- MongoDB Database Connectivity
- Professional Portfolio Layout

---

## 🛠️ Tech Stack

### Frontend
- React.js
- CSS3
- Framer Motion
- React Simple Typewriter

### Backend
- Node.js
- Express.js

### Database
- MongoDB Atlas

### Deployment
- Vercel (Frontend)
- Render (Backend)

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/NITIN00011/Portfolio_website.git
```

---

### Install Frontend Dependencies

```bash
npm install
```

---

### Run Frontend

```bash
npm start
```

---

### Run Backend

```bash
cd server
npm install
node server.js
```
